# 西瓜 Melon

AI 办公助手桌面应用。选一个技能，AI 帮你把事办完——不用学 prompt，不用记命令。

## 能做什么

| 技能 | 场景 |
|------|------|
| 翻译文本 | 中英互译，支持多语种 |
| 润色文案 | 写邮件、改报告、发朋友圈 |
| 整理文件 | 按类型自动分类，清理临时文件 |
| 搜索信息 | 帮你搜网页并总结要点 |
| 商品比价 | 跨平台比价格 |
| 批量重命名 | 按规则一次性重命名文件 |

## 安装

macOS 用户下载 `.dmg` 文件，拖到 Applications 文件夹即可。

## 配置

1. 打开 西瓜
2. 点击左下角齿轮图标打开设置
3. 输入 API Key
4. 重启应用

> API Key 通过 macOS 原生钥匙串加密存储，不会以明文写入任何文件。
